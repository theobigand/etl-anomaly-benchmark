# Manuscript table audit for rounding, units, denominators and provenance (T123-T125), 2026-11-19

Scope: every table of `paper/main.tex`. Method: each table body was regenerated from its archived results and compared
with the manuscript value by value; captions and headers were read for units, denominators, symbols and
stand-alone interpretability. No archived value was changed; where the regenerated value differed only in format, the
format was fixed.

## Findings corrected

1. **Scaling table, units.** The memory column mixed units: the seven detectors of the first campaign were in MB
   (10^6 bytes, for example 116 for the IQR), the ten later ones in MiB (2^20 bytes, for example 186 for ECOD). The column
   is now in MiB for every row (IQR 110) and the caption says so.
2. **Scaling table, rounding.** Times carried two or three significant digits depending on the row (`0.16 s`, `1.09 s`,
   `12.7 s`, `69 s`). All times now carry three significant figures; the over-budget and not-run cells are defined in the
   caption.
3. **Fixed-calibration caption** said the flag columns were a fraction while the values are percentages.
4. **Two-schema table caption** said six methods for a table of five; the header "Great Expect." is now the full name.
5. **Headers and symbols:** the `ROC` column is now defined in the caption of each table that has it (ROC-AUC); the
   fixed-calibration headers (`Flag train%`) follow the appendix (`Flag.% prev.`, `Flag.% fixed`).
6. **Stand-alone interpretation:** captions now define the abbreviations (`Contam.`, `Prec.`, `Rec.`, `Flag.%`, `prev.`,
   `Mem.`), the sign of paired differences, the meaning of `Problems`, the bold cells of the examples table and the
   unit of every percentage.

## Conventions applied

- Metrics in [0, 1] (AP, ROC-AUC, F1, precision, recall): three decimals in per-dataset and per-detector tables, two in
  summaries over problems, in the compact view and in the contamination table; the sign is explicit for differences.
- Percentages: two decimals below 1, one decimal from 1 (contamination table); the benchmark and fixed tables keep the
  three decimals of the archived means.
- Times: three significant figures with the unit in the cell; memory in MiB.
- A dash marks a detector not run on that size; `>300 s` marks a timeout and `not run` a size not tried after it.
- Denominators: `Problems` is the number of problems on which the detector ran (84 to 100), with the reason for the
  smaller counts in the text of Section "Labelled pool".

## Not done

No table was removed or merged, and no value of an archive was edited. The closure table is a record of a certified
campaign and is regenerated by hand from its report; it will be updated with the next certification.
