# Notes
Art direction: data-led deck for an engineering board. Evidence carries the design: one dot-matrix of the ground-truth sample, one POD line chart, one table, one sequence diagram. Georgia headlines that state the point, Helvetica Neue for data, hairline rules, no cards.

Imagery decision: no photograph or generated image. A blade image would not add context the audience lacks and could be mistaken for inspection evidence. The only illustration is the dot grid on slide 2, labelled as illustrative with arbitrary dot positions.

Palette derivation: warm off-white paper like unpainted composite. Colour is semantic, one hue per method, used consistently: ember orange for thermography (heat), deep teal for ultrasonic, neutral stone grey for visual (the baseline). Navy tech styling and gradients avoided.

Skill instructions followed: DESIGN_SYSTEM, ART_DIRECTION (visual role, imagery consideration, palette derivation), VOICE (point-stating titles, no em dashes, only brief facts; 56% is 230/410), PRESENTATION_RULES. Not done: bounded multi-composition review loop and voice script; checked visually only, in two render passes.
