# Notes

**Art direction.** Data-led role for an engineering review board. Opening is a dark typographic statement of the recommendation with the four campaign facts as a ledger, not a title plus image. Then ground-truth grid, POD chart, cost table with proportional bars, protocol diagram, limits. Titles state the point. Density varies: sparse cover and limits, dense table and chart.

**Imagery.** None. The subject has no supplied photograph and the evidence is relationships (POD, cost, false calls). The 240-cell grid is a labelled illustration; cell positions carry no data.

**Palette.** Derived from the methods, not a warm paper default: thermography uses a thermal-camera orange-red (#b8431c), ultrasonic a cool transducer teal (#1b5e6e), visual a neutral grey-green (#5d6965). The field is a pale glass-fibre grey-green (#f1f3f0), the cover and ink a near-black teal (#14201f). Colour encodes method only.
