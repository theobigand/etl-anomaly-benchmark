# Slides

`thesis_progress.html` is generated by `build_deck.py` (slide definitions in `deck_a.py`, `deck_b.py`,
`deck_c.py`, helpers and native charts in `deck_lib.py`, styling in `deck.css`). Edit those, then run
`python3 slides/build_deck.py` from the repository root. The HTML is a self-contained deck
(keyboard / dot / swipe navigation, one slide per viewport) with a `@media print` block that lays
each slide out as one 1280x720 page. Photographs and their provenance are in `art/`.

`thesis_progress.pdf` is rendered from it and committed. To regenerate:

```bash
make slides CHROME=/path/to/chrome        # or chromium, or chrome-headless-shell
```

Any Chromium-family binary with `--print-to-pdf` works. The figures are
pulled from `../paper/figures/`, so run `make heatmap`, `make curves` and
`make severity` first if those changed.

## Rendering used for review (2026-11-11)

The regular Chrome binary can hang; the Playwright headless shell is reliable:

```bash
CH=~/Library/Caches/ms-playwright/chromium_headless_shell-1248/chrome-headless-shell-mac-arm64/chrome-headless-shell
$CH --no-sandbox --headless --no-pdf-header-footer \
  --print-to-pdf=slides/thesis_progress.pdf "file://$PWD/slides/thesis_progress.html"
pdftoppm -r 150 -png slides/thesis_progress.pdf /tmp/slides   # review at 150 dpi, not 45-80
```

## Visual provenance

See `art/PROVENANCE.md`. Three generated still-life illustrations are used as openers and for the
mutation explanation, each labelled on the slide as an illustration. Charts and tables carry values
from the paper and verification notes; the 17 by 6 recall matrix and the mutation chart are drawn in
SVG from those values. The remaining figures are the archived PNGs of `../paper/figures/`.

## Art direction (2026-11-12)

Concept: raking light. A low light from the lower left shows what a regular surface hides, which is
the work of an anomaly detector and of a test suite. Amber marks what the light finds or what is still
open; steel marks what held under test; graphite slides carry claims and openers, bone slides carry
evidence read under the light. The numeric content follows `paper/main.tex`; where the earlier deck
differed (per-type recall of Isolation Forest 0.91, One-Class SVM 0.84, Z-score 0.92) it now follows
Appendix C (0.89, 0.90, 0.93).

Colour semantics: amber marks an anomaly found, an open item or an unsupported or failed result;
steel marks what held under test or the best of a column or chart; neutral ink carries numbers and
editorial emphasis (`.em`, bold only); matrices use the cividis scale (0 to 1) for measured recall, so
cividis yellow is a value, not a warning. Every coloured mark also carries a word or a symbol.
The composition inventory is generated to `docs/thesis-remediation/SLIDE_COMPOSITION_INVENTORY_2026-11-12.md`.
Known limits: the PR-curve and severity figures are still the archived matplotlib PNGs on a light sheet.
